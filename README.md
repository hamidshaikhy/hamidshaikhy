## Hey, I'm Hamid

I'm a **front-end developer** who enjoys the point where interface design meets application logic. I build with **React, Next.js and TypeScript**, turning ideas into responsive interfaces with clear structure and purposeful interactions.

My work ranges from a multilingual website for a real business to visual editors, document tools and a browser-based desktop experience. I'm especially interested in interfaces that involve more than displaying content: dragging, resizing, editing, searching, exporting and managing complex state.

I build **Persian-first and RTL experiences**, and I care about how an interface reads, responds and behaves on different screens. The visual details matter to me, and so do the loading states, validation rules and recovery paths behind them.
